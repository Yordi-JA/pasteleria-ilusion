Motivos decorativos de la marca.

- `duya-feston.svg`: borde de duya festoneado en `relieve` (#ecd2d2), 384 × 21px, doce festones de 32px. Para impresión y piezas fijas; en la web se dibuja con CSS (ver "La duya" en el libro de marca).
- `dibujo-vela.svg`, `dibujo-duya.svg`, `dibujo-base.svg`, `dibujo-toldo.svg`, `dibujo-rebanada.svg`, `dibujo-pisos.svg`: dibujos de línea de 64 × 64, trazo de 2px en `mermelada` (#5e1921). Para otro color, cambia el atributo `stroke`. Reglas de uso en "Dibujos de línea".
